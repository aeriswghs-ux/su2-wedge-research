# Sources

Read these sources before citing them in your own paper. Links are starting points; keep track of the version or page you actually use.

- [SU2: Inviscid Supersonic Wedge tutorial](https://su2code.github.io/tutorials/Inviscid_Wedge/). Describes the Euler wedge case, HLLC scheme and inlet/outlet behavior. The tutorial page identifies an older SU2 version; this project's actual executable was 8.6.0.
- [NASA Glenn: Oblique Shock Waves](https://www.grc.nasa.gov/www/k-12/airplane/oblique.html). Explains the shock relations and assumptions used by the equation solver.
- [SU2 downloads](https://su2code.github.io/download.html) and [SU2 8.6.0 release](https://github.com/su2code/SU2/releases/tag/v8.6.0). Official solver sources.
- [ParaView downloads](https://www.paraview.org/download/). Official visualization software source.
- [Python downloads](https://www.python.org/downloads/). Official Python source.
- [Educational oblique-shock example used by the starter tests](https://kursatkara.github.io/MAE3293_Fundamentals_of_Aerodynamics/calculators/oblique-shock.html). The starter's test compares with rounded numbers from this example. The present publication work does not claim a new independent audit of that webpage.

The original brief names textbooks and research papers as future reading. They are not presented here as sources newly read or verified during publication.
