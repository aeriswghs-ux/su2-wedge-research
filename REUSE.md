# Reusing this project

This repository is public so people can inspect and reproduce the study. A separate open-source license has not yet been selected by the repository owner. Do not assume that public access grants every kind of reuse or redistribution permission. Ask the owner before republishing substantial project material under a new license.

SU2, ParaView, Python and their dependencies have their own licenses. Their executables are not included in the release ZIPs. Links to official downloads do not transfer ownership of those programs to this project.

When discussing the work, identify the repository, release tag and file used. Do not call it peer-reviewed research or hide AI assistance.
