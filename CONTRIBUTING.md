# Help improve the project

Open an issue with the problem, the command you used, your software versions, and the relevant log. Remove personal paths before posting. If you suggest a scientific change, say which claim it tests and what evidence would support or reject it.

Keep changes small and explain them in simple English. Run `python -m pytest -q` after code changes. If a measurement method changes, compare the old and new methods and keep both results. Do not replace recorded evidence with invented or hand-adjusted CFD values.

New simulations belong in separate run folders. Ask a reviewer to check the science before treating a change as a stronger research conclusion.
